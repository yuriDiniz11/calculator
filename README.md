# Calculadora em C

Calculadora simples em linguagem C, criada para praticar lógica de programação durante o curso Técnico em Desenvolvimento de Sistemas (SENAC-RS).

## Evolução do projeto

O projeto foi construído em 4 versões, cada uma registrada em um commit:

1. **Versão 1:** calculadora com `if` e `else`.
2. **Versão 2:** adição do `switch case`.
3. **Versão 3:** código organizado em funções, ainda sem seleção de operador.
4. **Versão 4:** combinação de `if/else`, `switch case`, funções e escolha do operador pelo usuário.

- Tratamento de entradas inválidas: [descrever, ou remover esta linha]
